# Airbnb Data Analysis - Python

## Project Overview
This project explores Airbnb listing data to identify pricing trends and availability patterns. Since the dataset was provided by my university and is too large for direct upload, this repository contains the analysis code and a full static report of the findings.

## Key Technical Tasks
* **Data Cleaning:** Handled missing values in price and neighborhood data using Pandas.
* **Exploratory Data Analysis (EDA):** Visualized price distributions and correlation heatmaps using Seaborn and Matplotlib.
* **Manual Implementation:** Applied custom logic for data transformations rather than relying solely on automated libraries.

## Technologies Used
* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **Jupyter Notebooks**
